# Contributing

This research prototype welcomes genuine issue reports, pull requests, documentation improvements and independent testing.

1. Create a branch and describe the problem.
2. Add or update tests where feasible.
3. Run `python -m pytest -q tests/`.
4. Submit a pull request with a brief explanation of the behaviour changed and any remaining limitations.

Do not post API keys, identifiable client data, customer information, invented user feedback or sensitive meeting details. Do not claim independent performance or adoption without reproducible evidence.

**Licensing:** The maintainer has not yet chosen a top-level open-source licence. Ask before redistributing source beyond the rights granted by GitHub's terms.
